## 1. Общие правила и запреты

- Одна активная песочница за раз на ветку; параллельные запуски запрещены.
- Только `ops/sandboxes/runner/run-sandbox.sh`; прямые `docker compose` запрещены.
- Live-стенды не трогать: порты `8080 8081 8082 5434 6379 8123 8000` в deny-list, скрипт отказывает сам.
- `main`, `preview/*`, `devops` как цели — отказ (`main` — реальный деплой).
- Запрещены: `docker.sock`, `/`, `/etc`, `/root` монты, `privileged`, `0.0.0.0` бинды.
- Секреты в логи и вывод запрещены; `.env` в репо запрещён.

## 2. Запуск и встречи

```bash
./run-sandbox.sh start <web|ml|data>
./run-sandbox.sh status <web|ml|data>
./run-sandbox.sh exec <web|ml|data> <command...>
./run-sandbox.sh stop <web|ml|data>
```

Примеры — в шапке `run-sandbox.sh`. `stop` всегда в конце работы.

## 3. Порты (только loopback)

| Ветка | Порт песочницы | Живой порт |
| --- | --- | --- |
| web | `127.0.0.1:18081` → 8081 | `127.0.0.1:8081` |
| ml | `127.0.0.1:18082` → 8082 | `127.0.0.1:8082` |
| data | `127.0.0.1:18000` → 8000 + `16379` + `18123` | `8000/6379/8123` |

Проверка: `ss -tlnp`. Живые порты в песочнице — отказ скрипта.

## 4. Smoke

- `sandbox-smoke.yml` — advisory-only, деплои не гейтит.
- Матрица: `web|ml` — полный пилот; `devops` — negative (runner обязан отказать); `data` — только receipt-gate.
- Триггеры: push `web|ml|devops|data` + ручной dispatch.

## 5. Логи

- `run-sandbox.sh status`, `docker logs/ps/inspect`.
- Ресипты `smoke-<leg>.txt` (14 дней), `sandbox-smoke-digest.md` (30 дней).
- Перед публикацией лога — `grep` на секреты.

## 6. web

- Источник: `/opt/haklolarp-web`. Проверка: `curl 127.0.0.1:18081/`, `/api/v1/health`.
- Дельта от общего: нет, базовый пилот.

## 7. ml

- Источник: `/opt/haklolarp-ml`. Проверка: `curl 127.0.0.1:18082/health`.
- Дельта: долгие задачи — ждать завершения, артефакты забирать из volume, не из контейнера.

## 8. data

- Источник: `/opt/haklolarp-stack`. Проверка: `curl 127.0.0.1:18000/` + `verify.py streams`.
- Дельта: фикстуры/объём — после работы чистить свои данные; `down -v` запрещён (сносит тома).
