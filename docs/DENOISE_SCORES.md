# Скор денойза

Дата прогона: 2026-10-05. Числа — `python scripts/score_denoise.py`.
Полный JSON локально: `artifacts/denoise/scorecard.json` (в git не входит).

Меньший residual MAD сам по себе не победа: фильтр может съесть очаг.
Порог spatial Z и окно свидетеля заморожены. По ним метод не подгонялся.
Высокий Z после сильного сглаживания часто значит, что упал MAD масштаба,
а не то, что очаг сохранён лучше.

Операционный clean-канал детектора по-прежнему **median_x3**.
Канал сменится только после полного прогона восьми свидетелей, не по одной таблице ниже.

## Протокол

- Синтетика, шум σ = 0.35 °C, спайк +6 °C на трёх отсчётах, мёртвый хвост.
  Малое поле 12×80. Широкое 48×160 — единственное, где кроп U-Net 32×128 реально считается.
  На 12×80 сеть возвращает вход как есть: её строка там не является скором модели.
- `5.csv`, сырое поле. Контраст ядра 297–303 м против полос 280–290 и 310–320 м: **3.101 °C**.
  Высокочастотный MAD соседних разностей: **1.222 °C**.
- Тот же spatial Z (halo 8–40 м, порог 3.5) на раннем ядре `5-early-warm-core`, строки 20–201.
  Доля тревоги у всех методов около 1. Это проход/непроход, не рейтинг.

Мёртвые клетки после каждого метода остаются NaN (`dead_finite = 0`, `dead_alarms = 0`).

## 2D U-Net

Первая голова была residual и училась на дырках, забитых нулём.
На `5.csv` это удвоило контраст: hf 1.240 (не лучше сырого 1.222), контраст 6.574, удержание **2.120**.
В clean это не годится. Прогон снят до смены архитектуры, тем же скриптом.

Сейчас голова предсказывает температуру, дырка закрывается левым соседом,
на инференсе пиксель скрыт шахматной фазой 2×2 (Noise2Void).
3996 кропов, 6 эпох, CUDA, MSE 0.089 → 0.019, 6.6 с, `serve=scorecard`.
Веса: `models/weights/unet2d_n2self.pt`.

После смены удержание на `5.csv` стало 0.960, мёртвый хвост пустой.
Сеть не гладит файл сильнее TV и слегка задирает синтетический спайк.
Живой инференс на CPU-стенд не везём. Карточка — этот документ.
