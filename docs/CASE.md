# Постановка кейса МГТС

Хакатон «Телеком будущего». Направление: сенсорика и DSP.
Название: анализ данных распределённых волоконных сенсоров.

## Что измеряем

Оптоволокно лежит **в помещении** (офис, производство, HORECA, лифтовый холл)
и снимает температуру вокруг себя. Это поле `T(t, x)`:

- `t` — время профиля
- `x` — метры вдоль кабеля
- значение — °C

Виброакустики в выданных файлах нет. Классы «машина / копка / шаги» к этим
CSV не относятся.

Данные сырые, без разметки. `-300` — нет измерения, не холод.

## Что считать аномалией

Естественный фон: люди пришли, включили кондиционер — широкий участок
волокна плавно остыл.

Событие: локальный нагрев или охлаждение, достаточно долгое, иногда
периодическое, иногда в один момент на разных координатах. Пример
кейсодержателя: волокно вдоль силового кабеля насоса.

## Два этапа, которые ждёт жюри

1. Бинарно: есть событие / нет (`Normal` / `Anomaly`).
2. Тип — наши гипотезы по форме: `Background`, `HVAC_Cycle`,
   `Local_Heating`, `Local_Cooling`, `Periodic_Thermal`, `Sensor_Fault`.

Обязательны пояснительная записка и код. Docker-приложение — плюс.
Оценка идёт по тому, какие аномалии найдены и почему.
