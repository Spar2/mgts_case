# Как получить независимую разметку

`python scripts/prepare_annotation_queue.py` создаёт 232 предложения детектора
и 36 случайных окон для проверки пропусков и трудного фона. Предложения
включают все шесть файлов, их source SHA, интервалы строк `[start, stop)`
и координаты в метрах. У всех `expert_label=null`, `review_status=pending`.
Это черновой материал, а не автоматически объявленная экспертная истина.

Первому разметчику передать `blind_review.jsonl`, исходные температуры,
маски и временные отметки. Не показывать предложенный класс и Z.
`proposals.jsonl` хранится отдельно для последующего сравнения.

Для каждого окна отметить:

1. Достаточно ли наблюдений? Если нет, оставить класс неизвестным.
2. Есть ли локальное изменение относительно окружения? Определить начало,
   конец и пространственную поддержку, сохраняя разрывы наблюдений.
3. Форма: нагрев, охлаждение, повторяющееся изменение, широкое смещение,
   одиночный выброс, фон или неопределённо. Причину и неисправность датчика
   не назначать только по форме температуры.
4. Уверенность и объяснение. Для периодики — минимум три наблюдаемых
   повторения, интервалы и наличие пропусков между ними.
5. Второй разметчик проверяет спорные случаи и выборку согласованных.
   Расхождения сохраняются; решение согласования не заменяет первый ответ.

Сначала заморозить конфиг и критерии оценки, затем раскрывать новые метки.
Восемь прежних свидетелей остаются development/regression. Все текущие
шесть CSV уже изучались: новый разметчик делает метки независимее, но не
превращает измерения в невиданные объекты. Для оценки переноса нужны новые
временные периоды/объекты от кейсодержателя, полностью удержанные от настройки.

Протокол финальной оценки: event precision/recall при IoU, задержка,
ошибка границ, поддержка наблюдений, ложные события на кабель-сутки.
Бюджет ложных тревог согласовать с пользователем системы до настройки.
Случайные окна могут содержать события: им нельзя присваивать фон заранее.

Изоляция разметки и настройки соответствует принципу отдельной оценки
после выбора модели в [документации scikit-learn](https://scikit-learn.org/stable/modules/grid_search.html).
