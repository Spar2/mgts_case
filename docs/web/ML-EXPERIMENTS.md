# Эксперименты ML и контуры предложенных зон

Источник: ML-коммит `237168f4d4a3e11260c9f692880cc477cd7af779`. На сайте `/experiments` доступен неизменяемый снимок опубликованных результатов: 9 сочетаний метода/нормировки, калибровочные пороги, IoU/FAR-кривые, диагностика шести реальных CSV и два режима уточнения границ.

Рабочая пара остаётся `median_x3 + spatial_z_halo`, |Z| ≥ 3.5. Выбор на странице не запускает обучение, не изменяет настройки расчётов и не создаёт экспертных меток.

## Как читать страницу

- IoU и FAR относятся к синтетическому holdout. FAR означает долю фоновых ячеек, не ложные события в час.
- Синий график — исходный baseline, красный — выбранный метод. Его собственный порог показан отдельно. Точный просмотр точек доступен ползунком и клавиатурой. Кривая sampled с шагом 0.25, а сводка выбранного порога получена отдельным расчётом.
- Столбцы по реальным CSV показывают количество зон и долю отмеченных ячеек. Это диагностика изменения метода, без независимого аварийного эталона.
- Восемь witnesses — агентские development-regression наблюдения, не восемь человеческих ответов.
- У hybrid своя база из bounding boxes. Её IoU не сравнивается напрямую с threshold support из таблицы порогов. Уточнение не включено в рабочий контур: обнаружены ошибки геометрии и подсчёта исчезнувших масок.
- «Скачать исследовательскую сводку JSON» отдаёт только компактные показатели и происхождение, без CSV, crop-полей, журналов и учётных данных. Это не экспертный кейс.

## Архитектура

GET `/api/v2/ml-experiments` требует действующую сессию проекта local. API только чтение. Снимок в `services/web-api/research/ml-237168f/experiments.json` содержит SHA исходных JSON и ML-коммит; его собственный SHA закреплён в коде. Повреждение возвращает контролируемый 503 для исследовательской страницы и не меняет основной анализ. Исходный snapshot не обновляется автоматически при push в ml: новый источник требует проверки и явного обновления.

Пакет меньше 100 KiB; поля CUDA-метрик отображаются как авторский отчёт. Baseline независимо повторён на CPU, нейросетевой CUDA-прогон — нет. Сайт не устанавливает Torch и не запускает эти алгоритмы через страницу.

GET `/api/v2/result-runs/{id}/zones` возвращает геометрию предложений на физических границах исходных ячеек. Объекты с временным разрывом получают отдельные контуры; persist run и снимки кейсов не переписываются. `/analysis` показывает максимум 200 контуров, сохраняя выбор через существующий список зон. Контур — bounding box гипотезы, не точная маска и не экспертное подтверждение. Это геометрия сохранённого рабочего результата, не импорт нового hybrid refinement.

## Проверки

Локальная приёмка: 78 серверных тестов пройдено, 3 пропущено по условиям окружения; 14 клиентских тестов, TypeScript, ESLint, сборка и OpenAPI. Новый путь пройден в Chromium/Firefox/WebKit, включая 320/390/430/1440 px, клавиатуру и скачивание JSON. Проверены отсутствие запусков ML/экспертных записей, изоляция проектов и повреждение SHA пакета. Прежний путь реального расчёта → кейс → показ на защите также прошёл с контурами.

PNG: [1440 px](screenshots/experiments-1440.png), [390 px](screenshots/experiments-390.png), [контуры реального окна](screenshots/analysis-zone-contours.png).

Для будущего проверенного снимка:

```text
python scripts/package-ml-experiments.py --ml-checkout /code/ml --output /new-snapshot/experiments.json
```

Команда требует закоммиченные входы и не перезаписывает существующий файл. Флаг --baseline-cpu-reproduced является явным утверждением оператора после независимого повтора, по умолчанию он выключен. После ревью нового источника обновляются закреплённый SHA/путь в сервисе и документация; автоматического продвижения модели нет.

Проверяются SHA пакета, отказ чужому проекту и анонимному посетителю, отсутствие POST-управления порогом, совпадение сводки с исходными числами, клавиатура, мобильные размеры 320/390/430/1440 px и переход к расчётам нужной записи. Сценарий `qa-experiments.js` включён в CI с обязательными флагами фактического успеха. Основной исследовательский путь и экспорт кейсов проходят прежние проверки.
