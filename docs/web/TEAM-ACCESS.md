# Доступ к DTS Workbench

Командный сайт полностью закрыт входом. Без сессии доступны только `/login`,
формы `/activate` и `/recover` для одноразовых ссылок и статические ресурсы.
Главная, `/try`, `/request-access` и прежние публичные API больше не открывают данные
анонимному посетителю. Рабочие прямые ссылки сохранены; после входа восстанавливается
совместимый внутренний маршрут. Инструкция оператора: [CLOSED-TEAM.md](CLOSED-TEAM.md).

## Участнику

1. Получите приглашение от администратора через личный канал связи.
2. Откройте ссылку в браузере, задайте логин, имя и собственный пароль от 12
   символов. Разрешены вставка и менеджеры паролей.
3. Войдите через `/login`. Роль и проект уже определены приглашением: форма не
   позволяет назначить себе права.
4. Откройте «Аккаунт»: там можно сменить пароль, посмотреть активные сессии,
   завершить одну или остальные. Смена пароля завершает все сессии.

Приглашение действует 24 часа, используется один раз. Простое открытие страницы
его не расходует; занятый логин тоже не расходует. Секрет ссылки удаляется из
адресной строки и остаётся только в памяти. Если обновить страницу активации,
снова откройте исходную ссылку. Не пересылайте её посторонним.

Сессия действует максимум 12 часов и заканчивается после 30 минут бездействия.
Фоновые обновления очереди не считаются активностью. Перед завершением появится
предупреждение. Серверные ответы не теряются при выходе; несохранённые изменения
нужно отправить до завершения сессии.

При потере пароля свяжитесь с администратором через ранее известный канал.
После подтверждения личности он передаст ссылку на 30 минут. Вы зададите пароль
сами, после чего войдёте обычным способом. Все старые сессии и ссылки
восстановления будут отозваны.

## Администратору

В «Аккаунте» или «Системе» создайте приглашение, выбрав роль. По умолчанию это
`viewer`. При приглашении администратора потребуется повторно ввести **свой**
пароль. Ссылка показывается только при создании; хранится только её SHA-256.
Ненужное приглашение можно отозвать. Участник выбирает пароль самостоятельно.

Заявки доступа находятся в «Аккаунте» администратора локального проекта. Они
содержат имя, контакт и обоснование. Одобрение заявки само по себе не выдаёт
прав: отдельно создайте приглашение и передайте его проверенному человеку.
Закрытые заявки удаляются через 30 дней; очистка выполняется при работе с
заявками и ежедневным служебным процессом резервного копирования.

Перед выдачей восстановления проверьте личность через **ранее известный**
канал, а не через новый контакт из сомнительного сообщения. Восстановление
многопроектного аккаунта требует оператора, чтобы администратор одного проекта
не менял доступ ко всем остальным. Авторство старых ответов не переназначается.

## Матрица прав

| Действие | Посетитель | viewer | expert | analyst | admin |
|---|---|---|---|---|---|
| Вход и активация одноразового приглашения | Да | Да | Да | Да | Да |
| Рабочий архив своего проекта | Нет | Да | Да | Да | Да |
| Независимый экспертный ответ | Нет | Нет | Да | Нет | Да |
| Вычисления и импорт подготовленного результата | Нет | Нет | Нет | Да | Да |
| Свой пароль и сессии | Нет | Да | Да | Да | Да |
| Приглашения, аккаунты, восстановление | Нет | Нет | Нет | Нет | Да |
| Заявки доступа и метрики | Нет | Нет | Нет | Нет | Да |

Архив шести записей пока относится к проекту `local`. Другие проекты не получают
к нему доступ через смену заголовка. Роли не дают права видеть чужой проект.

## Исторические демонстрационные ответы

Прежний публичный сценарий отключён в командном сайте. Сохранённые ранее
демонстрационные заметки — заметки в памяти страницы, а не экспертные метки. Они
попадает только в скачанный отчёт. Публичный посетитель не создаёт задания,
репетиционные сессии или обучающие данные. Обработка `median_x3` подготовлена
заранее и не подтверждает наличие события. Исходные значения, маски, координаты
и SHA доступны отдельно от обработанного слоя.
