# Анимация автоэнкодера

16 октября 2026. Локальная ветка `animations2`, checkout `C:/dev/mgts/web-animations2`, база `885b96a`.

## Результат

На публичном лендинге после блока фактов добавлена одна интерактивная Canvas-сцена по присланной пользователем картинке **ConvAutoencoder: input 1×32×64**. Локальный предпросмотр: `http://127.0.0.1:5186/`, раздел «Как устроен автоэнкодер».

Семь состояний: `1×32×64 → 16×32×64 → 16×16×32 → 32×16×32 → 32×8×16 → 16×16×32 → 1×32×64`. Пояснения к свёрткам, pooling и декодеру, сканирующее окно и движущийся каркас с изменением формы между слоями. Время сцены — 24 секунды, это редакционный тайминг, не время исполнения модели.

Есть запуск, пауза, возврат к началу, ползунок и прямой выбор слоя. Автоматического старта нет. На узком экране выбранный слой увеличивается; полная последовательность остаётся доступна через кнопки. Обе темы используют Carbon/IBM Plex. Геометрия сцены вычисляется из времени, накопленной симуляции нет.

## Границы

- Иллюстрация не запускает модель и не выдаёт декоративные значения за результат. Источник — изображение команды, не текущий `ConvBackgroundAE` из Python и не `08_mae` из нового комплекта схем.
- Внутреннее представление содержит 4096 активаций против 2048 входных значений. Уменьшение пространственных осей не названо уменьшением общего числа активаций.
- Маршруты, авторизация, API, ML-код, логотипы, существующие возможности и остальные разделы не менялись. В `landing.tsx` добавлены только импорт и экземпляр компонента. Изменения другой ветки `Animations` не переносились.
- Коммита, push и deployment нет. Это локальный результат; CI и внешний стенд не проверялись.

## Проверка

Итоговая сборка: `npm run build` (TypeScript + Vite) — успешно. `npm run lint` — успешно. `npm test` — **84 теста, 14 файлов**, успешно. В зависимости Carbon остаются предупреждения Sass о deprecated `if()`; новых ошибок сборки нет.

Chromium через встроенный браузер, production preview на 5186:

- Проверены светлая и тёмная темы, исходная и выходная сетки, pooling и latent.
- Реальное воспроизведение прошло с 3 до 12,5 секунды; пауза сохранила 12,5 секунды между обращениями. Проход до конца ранее остановился на 24 секундах.
- На 1440 px высота плеера при переключении вход → latent осталась `782.66 px`, прокрутка после установившегося положения — без изменения.
- На финальной сборке для входа и latent: 320 px — `813.74 px`; 390 px — `833.75 px`; 430 px — `865.17 px`. Внутри каждой ширины высота и прокрутка совпали. Горизонтального переполнения страницы нет; полоса слоёв имеет собственную горизонтальную прокрутку.
- Ползунок управляется клавишами Home/ArrowRight. Кнопки доступны с клавиатуры.
- `prefers-reduced-motion: reduce`: запуск недоступен, выбор слоёв работает. Возврат к обычной настройке снова разрешает запуск. Найдено и устранено несоответствие установленного `useReducedMotion` ожидаемому динамическому обновлению: компонент подписан напрямую на `matchMedia` и снимает подписку при размонтировании.
- Анимационный цикл очищается при размонтировании, уходе из видимой области, скрытии вкладки и reduced motion. React-state меняется при выборе этапа и управлении, а не на каждом кадре; матрицы в состоянии React отсутствуют.
- Ошибок в журнале страницы Chromium после проверок нет.

Firefox, WebKit, количественный FPS/профиль памяти, видеорендер и автономный HTML в этой задаче не проверялись и не заявляются готовыми.

Итоговый снимок локальной страницы: `.runtime/autoencoder/preview-light.png` (не коммитится). Контрольные суммы обновлены только для разрешённых файлов анимации и двух строк подключения в лендинг.

## Доработка переходов 16 октября

По прямому отзыву пользователя исправлены скачки подсветки и пересечение номеров с объёмами:

- Диаграмма, нижний индикатор и пояснения используют общий `autoencoderFlow(time)`. Вес плавно передаётся между соседними слоями в течение этапа; позиция и её скорость непрерывны на границах.
- Вместо смены фона у кнопки по булевому флагу движется один индикатор. На узком экране прокручивается только полоса этапов. Ширины измеряются с дробной точностью; индикатор обрезается границами трека, чтобы округление не создавало случайную полосу прокрутки и скачок высоты.
- Ручной выбор слоя и возврат к началу выполняются с плавным переходом 450–900 мс. Повторное действие отменяет предыдущий переход; переключение reduced motion, скрытие страницы и размонтирование освобождают цикл.
- Сканирующее окно движется непрерывно по косинусной траектории. Соседние ячейки подсвечиваются мягкой волной, между слоями движется небольшой поток ячеек и меняющий форму каркас. Это иллюстрация архитектуры, не вычисленные активации.
- В мобильной версии геометрия и цвет одного увеличенного объёма интерполируются между этапами. Подписи и пояснения кратко затухают при смене, сохраняя зарезервированную высоту.
- Номера вынесены в отдельную строку `y=70`; ближайший объём начинается ниже `y=93`. Разделение проверяется тестом для всех семи слоёв.

После изменений: build/TypeScript и lint успешны; **87 тестов в 14 файлах** проходят, включая непрерывность на каждой границе и сохранение суммы весов подсветки. В Chromium наблюдались промежуточные дробные позиции индикатора при прямом и обратном переходе, обе темы и увеличенный мобильный слой. На 390 px при всех снятых промежуточных кадрах высота была `833.75 px`, переполнения страницы не было. После исправления округления полоса этапов на широком экране не имеет горизонтального переполнения. Reduced motion останавливает движение и оставляет немедленный ручной выбор слоя. В журнале страницы ошибок нет.

Изменения ограничены компонентом автоэнкодера и его тестами. Ветка остаётся `animations2`; коммита, push и deployment нет.
