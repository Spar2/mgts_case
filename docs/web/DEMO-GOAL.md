# Демонстрационный продукт: цель и приёмка

Начало: 10 октября 2026. База `web`, `42b8d4c`. Источник требований — пользовательская Goal-цель. Этот файл фиксирует полный объём, а не объявляет его выполненным.

## Этапы

1. Серверная репетиция: неизменяемый контекст источника/очереди/границ, отдельный ответ, защита рабочего журнала, воспроизводимость после обновления и перезапуска.
2. Carbon-маршрут: измерение → наблюдение → сравнение → проверка → отчёт. URL сохраняет шаг, профиль и координату; клавиатура и телефон поддерживаются.
3. Основание вывода: исходное поле, точный профиль, ряд, маски, соседний контекст, версии и согласованные шкалы; интеграция подготовленных результатов.
4. Отдельный технический архивный replay с принятием/сохранением/DSP, отменой и возобновлением без остановки общих сервисов.
5. Preflight, ограниченная предзагрузка, автономные HTML/JSON, инструкция докладчика и адаптер Захара, актуализация документации.
6. Реальные массивы, серверные/клиентские/браузерные проверки, ошибки сети и результатов, мобильные размеры, reduced motion, измерения и обновление 8081; локальные коммиты.
