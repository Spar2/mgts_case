# API v1 и числовой протокол

OpenAPI: `services/web-api/openapi.json`, интерактивно `/docs`. Типы клиента генерируются в `apps/web/src/api-schema.d.ts`.

| Метод | Путь после `/api/v1` | Содержание |
|---|---|---|
| GET | `/records`, `/records/{id}` | Каталог, источник/SHA, диапазоны, scale p1/p99, координаты, timestamps и сегменты |
| GET | `/records/{id}/tiles?x0&x1&t0&t1&width&height` | Физический диапазон; до 256×256, прямой median valid либо исходная сетка при приближении |
| GET | `/records/{id}/slices?row&column` | Точный исходный профиль, временной ряд, point value и маска |
| GET | `/queue` | Карточки без методов/selection rationale, ответы и SHA очереди |
| GET | `/queue/{id}/window` | Нативные ячейки окна; до 200 000 значений |
| GET | `/queue/{id}/methods` | Небольшая сводка количества кандидатных ячеек после ответа |
| GET | `/queue/{id}/methods/{method}/window` | Подписанная гипотеза −1/0/+1 на исходной сетке после ответа |
| POST | `/reviews` | Строгий Review, `Idempotency-Key`, `expected_revision`; конфликт 409 |
| GET | `/export` | `general-review-packet-v1`, latest revisions, reviewer_type, no training targets |
| POST / GET / DELETE | `/replays`, `/replays/{id}` | Ограниченная сессия replay, снимок, закрытие |
| POST | `/replays/{id}/commands` | play/pause/seek(row)/speed(1,10,60) |
| GET | `/replays/{id}/events` | SSE cursor + heartbeat, reconnect получает текущий снимок |
| POST | `/denoise` | Один профиль через отдельный ML API |
| POST / GET | `/jobs/detect`, `/jobs/{id}` | Ограниченная фоновая задача анализа; queued/running/complete/failed |

Изменения требуют `X-Workbench-Token`, получаемый через `/session` на доверенном локальном Host (в командном режиме он связан с авторизованной сессией; login получает сессию отдельно). Тело ограничено 64 KiB, кроме импорта `/results`, где лимит 256 KiB. Source SHA — идентичность данных; имя файла служит удобным локальным ключом, а не глобальной идентичностью.

Если сервер отклонил именно устаревший mutation token, клиент обновляет его и делает одну повторную попытку с тем же ключом действия. Сетевую ошибку и остальные отказы он автоматически не повторяет: состояние записи могло быть неподтверждённым. Ручной повтор сохранения сохраняет ключ идемпотентности для того же тела.

## Бинарный пакет версии 1

Все числа little-endian. HTTP может сжимать пакет; `fetch.arrayBuffer()` получает распакованные байты.

1. `uint32` — длина JSON-заголовка в байтах.
2. UTF-8 JSON: `version=1`, `shape=[rows,columns]`, `source_sha256`, `scale`, `aggregation`; обзор — `x_edges/time_edges`, native — `x_cells/time_cells` (пары границ каждой ячейки).
3. Нулевой padding до границы 4 байт.
4. `rows*columns` Float32 values в row-major.
5. Столько же Uint8 mask codes.
6. Нулевой padding до границы 4 байт относительно начала массива values.
7. Столько же Uint32 valid-observation counts.

Температурный слой имеет единицы °C и Cividis. Гипотезы имеют `palette=diverging`, отдельное название и единицу «знак». Mask !=0 исключает значение из температурной визуализации; NaN в пустом агрегате не превращается в ноль. Worker проверяет длину/версию/размер пакета и переносит ArrayBuffer без дублирования transfer entries.

## Память и кэш

Большие бинарные буферы находятся в отдельном LRU: 64 MiB при desktop-загрузке страницы, 32 MiB при mobile-загрузке. Это бюджет **бинарного кэша**, не всей памяти вкладки. Worker/GPU и декодированный текущий блок учитываются отдельно. Один нативный блок прежней очереди ограничен 200k ячеек, обзор — 65 536. Адаптер исследовательского пакета допускает окно до 1M, но большие поля выдаёт обзорными физическими блоками, не одной огромной текстурой.

Отрисовка использует instanced WebGL2, DOM-оси и Canvas2D fallback; GPU не фильтрует температуру между ячейками. Очистка удаляет buffers/textures/programs. При потере контекста поле переходит на Canvas2D. Линии строит uPlot; числа прореживает worker.

Диагностика `window.__dtsCacheStats()` возвращает бюджет/размер LRU. `window.__dtsGraphicsStats()` отдельно считает запрошенные vertex buffers, текстуру палитры и оценку одной RGBA поверхности на каждый Canvas. Это не точный VRAM: память драйвера, compositor и двойная буферизация в счётчик не входят. Диагностика не содержит температур, токенов или ответов.

Query хранит метаданные, небольшие срезы и mutation state; старые срезы удаляются после 10 секунд без подписчика. Серверный кэш физических блоков ограничен 256 MiB, ключ включает source SHA, диапазон, размер и версию агрегации. При смене области fetch отменяется, устаревший worker завершается.

## Исследовательский workspace

`GET /api/v1/packages` описывает независимые пакеты `general` и опциональный `real-data-v2`. У каждого свой SHA очереди, происхождение и shortlist. `GET /candidates?package=...&shortlist=true` возвращает исходные полуоткрытые индексы окружения и отдельно предложенные границы ядра. Эти границы не являются экспертным ответом.

`POST /regions/evidence` принимает `Region`: record_id, row_start/row_end, column_start/column_end. Проверяются исходные оси и бюджет 1M; ответ сохраняет настоящие координаты, время, маски, покрытие и разрывы. Числовой preview — явно обозначенная подвыборка индексов; у каждой показанной ячейки собственные физические границы. Экспорт не заполняет пропущенные ячейки интерполяцией.

`GET/POST/DELETE /bookmarks` сохраняет контекст исследования. `GET /runs` возвращает только метаданные и компактную сводку; `GET /runs/{id}` — подробный результат. `POST /results` принимает `dts-method-result-v1`: точный SHA источника, Region, метод/версию/параметры, время расчёта, заявленное происхождение обучения, ограничения и результат. Импорт JSON не является импортом весов или доказательством качества модели. Инструкция — в RESULT-HANDOFF.md. Ограничение запроса 256 KiB, UI допускает файл до 240 KiB. `denoised` относится к одной указанной строке и содержит полный исходный профиль; маски исходника сохраняются.

`POST /reports?format=html|json` сохраняет данные выбранного участка и профиля; необязательный run_id выбирает конкретный сохранённый результат. Без run_id экспортируется исходник; method сам по себе не выбирает обработку. HTML автономен, без JavaScript, с inline SVG поля/профилей и происхождением. JSON содержит точные числовые значения. Ответ эксперта добавляется только из указанного independent-журнала и при совпадении исходных границ окна. Отредактированная область не наследует чужую метку.

Для всех маршрутов проверки новый UI передаёт `package`, `independent=true`, `reviewer`. SHA очереди и имя выбирают журнал, ожидаемая ревизия и ключ идемпотентности защищают запись. В командном режиме личность и права определяются серверной сессией; reviewer должен соответствовать аккаунту. Старый локальный API без independent сохранён для совместимости и не заменяет командную авторизацию.
