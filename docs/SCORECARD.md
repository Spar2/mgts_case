# Витрина моделей

Дата: 2026-10-05. Каталог строк: `fiber/benchmark/vitrine.py`.
Latency сетей и детекторов: `python scripts/score_vitrine.py`
(локально `artifacts/benchmark/vitrine_latency.json`, в git не входит).

Это одна таблица уже посчитанных протоколов. Число из колонки денойза
не сравнивается с F1 детекции и с recall классов. Синтетический F1 и
recall посаженных сцен не являются точностью на кабеле.
`expert_confirmed = false` у всех свидетелей.

Операционная пара не сменилась: clean-канал `median_x3`, статус ставит
`spatial_z_halo`. Сети помечены `serve=scorecard`: на CPU-стенд их инференс
не везём. `serve=api` — метод денойза, который процесс на порту 8082 умеет
вызвать и который статус не ставит.

Колонка времени отвечает только на вопрос о будущих профилях.
Пространственные соседи вдоль кабеля у профильного фильтра есть.
`офлайн` значит, что кроп или зона содержат более поздние строки, чем
первая строка окна.

Latency DSP — один проход `5.csv` из [DENOISE_SCORES.md](DENOISE_SCORES.md), CPU.
Latency детекторов — один проход сохранённого `median_x3` файла 5, CPU, 2026-10-05.
Latency сетей — медиана 10 прямых проходов после 3 прогревов, CUDA, RTX 4080 SUPER.
Короткий батч и целый файл — разные работы.
