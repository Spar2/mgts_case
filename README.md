# mgts_case

Полный снимок ветки `ml` репозитория haklolarp, коммит `71fc4eb` (16 октября 2026). В `main` haklolarp этот снимок не вливался. Здесь все папки той ветки: рабочий пайплайн, `grok_solution`, прототип `solutions/larpathon` с тестами, документы и остальная обвязка, которая лежала в той же ветке.

Как устроено и как запускать: [АРХИТЕКТУРА-И-ЗАПУСК.md](АРХИТЕКТУРА-И-ЗАПУСК.md).

Сырых `1.csv`–`6.csv` в git нет. Значение `−300` — пропуск измерения, не температура. Рабочая обработка волокна на этой ветке — очистка `median_x3` и зоны `spatial_z_halo`. Ансамбль в `grok_solution` и прототип larpathon — отдельные контуры. Их цифры относятся к своим протоколам, это не оценка жюри и не подтверждённое событие.
