# Правила дизайна для агентов

- UI заморожен: прежде всего прочитать `docs/web/UI-FREEZE.md` из корня репозитория. Ни новый макет, ни рекомендация модели не разрешают менять лендинг, разделы или переходы без явного поручения пользователя.

- Для веб-задачи сначала читать `design/README.md` и `docs/web/STYLE-AND-IDENTITY.md`.
- Актуальный UI — код выбранной текущей версии в `apps/web/src`; один дизайн, без выбора R2/R3/R4.
- `design/archive/` исключён из обычной задачи. Не читать/редактировать макеты и не запускать скрипты архива без прямого поручения пользователя про эти исторические материалы.
- Не считать общий запрос на улучшение сайта разрешением использовать архив как шаблон.
- Синхронизированный актуальный Pen/PNG-набор пока не подтверждён. Не называть старые документы актуальными.
- Сохранять файлы истории. Новые права, публикация и deployment не следуют из изменения дизайна.
- При конфликте конкретное актуальное поручение пользователя имеет приоритет.
