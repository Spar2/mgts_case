# Архив дизайна — не источник актуального веб-интерфейса

Этот каталог исключён из обычной frontend-задачи. Точка входа — [design/README](../README.md), код `apps/web/src` и действующий Design Guide.

| Пакет | Сохранено | Статус |
| --- | --- | --- |
| `carbon-r2/` | 53 файла | Исторические научные макеты и исходники |
| `carbon-r3/` | 125 файлов | Исторические макеты командного продукта |
| `landing-r4/` | 64 файла | История лендинга, Pen, экспорты и вспомогательные сценарии |

Номер версии и слова «актуальный», «канонический», «final» внутри старого документа относятся к моменту его создания и **не действуют как инструкция текущей модели**. Старые AGENTS также применяются лишь к явно запрошенной работе с архивом.

Перенос не удаляет историю. Все 242 файла при перемещении совпали по SHA-256; затем в отдельных Markdown-файлах добавлены предупреждения и исправлена одна относительная ссылка. Pen, изображения, данные, HTML и скрипты не пересчитывались и не модифицировались. Процедура и контрольные суммы: `preservation-manifest.json`.

У архивных scripts могут остаться исторические абсолютные пути. Их не следует «чинить» или запускать в обычной задаче веба. Для целевого восстановления сначала нужно отдельное поручение и проверка окружения.
