# Лендинг: редактируемые макеты и материалы R4

Пакет передаёт Pen-документ, исходные логотипы, PNG и историю локальной подготовки лендинга. Рабочая реализация — `apps/web/src/landing.tsx` и `landing.scss`. Актуальные правила: [STYLE-AND-IDENTITY](../../../docs/web/STYLE-AND-IDENTITY.md).

- `landing.pen` — редактируемый документ. Открывать через Pen, не править как JSON.
- `assets/` — оригиналы квадратных логотипов, без обрезки.
- `png/`, `previews/`, `mobile-review/` — экспорты разных стадий. Имена соответствуют ID узлов Pen. Это архив макетов, **не доказательство актуального вида React-приложения**.
- `*.jpg` в корне — снимки промежуточных вариантов расположения логотипов и страницы входа. Название файла не делает вариант согласованным; текущие решения описаны в гайде.
- `visual-data.json` — ограниченный опубликованный фрагмент `5.csv / review-00018`, не исходный CSV и не полный рабочий архив.
- `*.js`, `prepare_visuals.py`, `run-pen.ps1` — вспомогательные сценарии автора. Они могут зависеть от локальных абсолютных путей, версии Pen и ID узлов; не запускать всю цепочку автоматически на новой машине. Для обычного редактирования достаточно Pen и [PEN_GUIDE](../carbon-r3/PEN_GUIDE.md).

Последние изменения React, включая белую страницу/серые панели, не синхронизируются с Pen автоматически. Перед правкой определить нужный экран и сохранить оригиналы Захара. Для новой приёмки экспортировать PNG и отдельно проверить браузер. Видео и временные CLI-логи в этот пакет не включаются.
