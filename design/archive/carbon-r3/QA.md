# Проверка дизайна R3

9 октября 2026. Это проверка файлов дизайна и экспорта, не доказательство работы будущих сервисов.

## Выполнено

- 53 новых корня: 32 desktop 1440×1000, 18 phone 390×844, один phone 320×844, landscape 844×390 и tablet 1024×900.
- На всех новых корнях выполнен отдельный после отрисовки `Get` с проверкой проблем геометрии: списки проблем пусты.
- Просмотрены обзорные листы первых 42 экранов и полные ключевые изображения: исследование, экспертный ответ, мобильное поле, смена пароля, второй фактор, экспорт/права с телефона, планшет, клавиатура и компонентные состояния. Дополнительные формы приглашения и роли используют проверенную форму с четырьмя полями.
- Экспортированы 53 PNG 2x из desktop Pen. Проверены декодирование PNG, точные размеры и SHA-256; индекс — `manifest.json`.
- 53 отдельных `.pen` созданы через официальный CLI 0.3.10, каждый повторно открыт. Каждый содержит один нужный корень; проверка проблем layout вернула пустой список.
- Общий переносимый Pen содержит 76 корней: 53 R3 + 19 R2 + 4 оригинала. Структура общего проекта сверена с текущим холстом через `Get(depth=30, includePathGeometry=true)`.
- Все 23 корня R2 и оригиналов отдельно сопоставлены с опубликованным Pen R2; нормализованные структуры не изменились.
- Сверка учитывает нормализацию x/y корня, сортировку ключей и эквивалентность обычного начертания (`normal`, `400`, отсутствие свойства). CLI при загрузке добавляет `fontWeight: normal`; без этой нормализации сериализации различаются при сохранённом содержимом. Используется длина JSON и FNV-1a — это проверка структуры, не криптографическое доказательство и не pixel-perfect утверждение. Итог по отдельным файлам — `pen/validation.json`.

Научные графики используют существующие данные и геометрию R2. Новые mock-ответы не записывались в SQLite и не превращались в training targets. Оригиналы Захара не редактировались. Новая навигация зависит от роли, а схема разрешений фиксируется отдельно от видимости меню.

## Ограничения и исправления при упаковке

В CLI app-режим сохраняет активный документ; параметр `--out` не создал отдельную копию. Исправлено: сначала сохранение активного файла, затем headless загрузка сохранённого источника и запись переносимого проекта в целевой каталог. Переносимый проект проверяется отдельно от активного холста.

В ограниченном headless-окружении были предупреждения о скачивании внутреннего Noto Sans и записи служебного состояния CLI. CLI выполнил чтение/сохранение и вернул проверяемые структуры, но эти предупреждения не доказывают идентичный рендер шрифтов на любой машине. Публикуемые PNG получены из desktop Pen; при открытии у участника нужно проверить IBM Plex и визуальное соответствие. Временные логи не публикуются.

Статический Pen не проверяет hit areas DOM, Tab/focus order, screen reader, auto-fill, изменение viewport экранной клавиатурой, safe area, реальные жесты, server ACL и offline-синхронизацию. Их критерии находятся в `MOBILE_UX.md` и `PRODUCT_SPEC.md`. Соответствие WCAG не заявлено.

Галерея — обычный HTML с локальными относительными ссылками на PNG. GitHub показывает исходник HTML; скачайте репозиторий и откройте файл у себя либо смотрите `SCREEN_INDEX.md` непосредственно на GitHub.
