# Дизайн: один актуальный источник

**UI зафиксирован по поручению пользователя 15 октября 2026.** Сначала читать
[UI-FREEZE](../docs/web/UI-FREEZE.md). Лендинг, разделы и переключения нельзя
менять без явного разрешения на конкретную правку. [Промпт для Grok](../docs/web/GROK-WEB-GUARDRAILS.md).

Для обычной работы над вебом источник истины — **код текущей принятой версии приложения** и [Design Guide](../docs/web/STYLE-AND-IDENTITY.md). Это одна система дизайна, не набор равноправных R2/R3/R4.

## С чего начинает модель

1. Проверить задачу пользователя, AGENTS, ветку, SHA и `git status`.
2. Прочитать [гайд](../docs/web/STYLE-AND-IDENTITY.md) и [UI-контракт](../docs/web/design-system/ui-contract.json).
3. Читать и менять нужный компонент в `apps/web/src`, затем проверить именно эту сборку в браузере.

| Предмет | Актуальный источник |
| --- | --- |
| Поведение и layout рабочего экрана | Компонент в `apps/web/src` и используемые им стили |
| Общие поверхности, шрифты, сетка | `apps/web/src/styles.scss` и Design Guide |
| Лендинг | `apps/web/src/landing.tsx`, `landing.scss` |
| Логотипы и опубликованный пример | `apps/web/public/landing/` |
| Контракты данных и доступа | Серверный код, OpenAPI, действующие API-обёртки |
| Синхронизированный актуальный Pen | **Не подтверждён. Не подставлять старый документ** |
| Каноническая актуальная PNG-галерея | **Не подтверждена. Старые экспорты её не заменяют** |

Наблюдаемые локальная версия, проверенный коммит и deployed SHA могут различаться. Это состояния проверки/доставки **одного продукта**, не три варианта дизайна. Сначала установить, какую версию правим и какую смотрим.

## Архив исключён из обычной задачи

Все прежние Pen, PNG, галереи и вспомогательные design scripts перенесены в `design/archive/`. Они сохранены ради истории; их не следует читать, редактировать, запускать или брать за визуальный образец в обычной задаче по вебу.

Открывать архив можно **только по прямому поручению пользователя, относящемуся к истории или конкретному старому файлу**. Общая просьба «улучши сайт» не является таким поручением. Если нужно спроектировать новый экран, исходить из текущего приложения; не выбирать автоматически самый поздний номер архивного пакета.

Если пользователь отдельно просит актуальный Pen, создать/синхронизировать его с конкретной текущей версией кода и проверить в Pen. Лишь после такой работы можно объявлять документ актуальным и добавлять его в эту таблицу. Сейчас такого утверждения нет.
