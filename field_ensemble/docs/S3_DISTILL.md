# S3 DISTILL — один U-Net вместо ансамбля

Ученик — один `DTSUNet` ширины 16. Учитель — замороженный `ens_u2ft_tcn_lgbm` (равное среднее `unet_w24`, `unet_v810ft`, `tcn`, `pixel_lgbm`). Обучение только на синтетике. Реальные CSV не читались: ни градиент, ни порог, ни калибровка.

Отбор — пиксельный IoU при FAR 1e-3 на synth v8 val. Порог — квантиль чистого фона (`valid & ev==0 & nu==0`) этого val, затем он заморожен для v8 test, v10 test и v11 test. Test в выбор не входит. Вложенная проверка — те же фолды, что `scripts/s3_sel2_cv.py` / `scripts/s3_sel_core.py`: `sequence_folds` (`i % k` по отсортированным именам), порог FAR 1e-3 только по фону holdout, micro-IoU по сумме tp/fp/fn. Прирост на k=5 считается против победителя под той же процедурой. Планка продвижения — не меньше 0.003. Абсолютный бар `nested_verdict` (0.3897) пишется в JSON и сам по себе победителя не назначает: на вложенном micro сам ансамбль сидит ниже этого бара.

`BEATS_WINNER` пишется только если одновременно: пересчёт победителя совпал с публикацией, val IoU ученика строго выше 0.386712 более чем на 1e-4, прирост nested k=5 не меньше 0.003, v10 и v11 не хуже опубликованных 0.403898 и 0.403900.

## Почему карты train считались заново

В `artifacts/pred/v8|v10/ens_u2ft_tcn_lgbm/` лежат val и test (v8) и test (v10, v11). Каталога `train` нет ни у ансамбля, ни у четырёх членов. Мягкие цели для градиента собраны скриптом из тех же весов, с которыми сохранённые карты совпали: на v8 val `seq0115` максимум `|Δs|` ансамбля 1.2e-7, по членам не больше 1.8e-7. Расхождение `h` — квантование float16 сохранённой карты (до 4.6e-4). Веса `artifacts/stage1/*.pt` и `pixel_lgbm.joblib` только читаются; перед концом обучения их sha256 сверяется. В `models_release/` и в каталог карт победителя скрипт не пишет.

Узкий кабель длиннее 2.2e6 пикселей в учитель не входит: полный проход LightGBM по такому файлу не укладывается в бюджет. Берутся до 32 последовательностей v8+v10 train, круг по шаблону. Около 10 % из них — holdout прокси (потеря дистилляции), не val. Прокси не двигает официальный порог.

## Потеря

Из `s` и `h` собирается симплекс: `p_фон = 1−s`, `p_нагрев = (s+h)/2`, `p_охлаждение = (s−h)/2`. Отрицательные доли от float16 обнуляются и перенормируются.

Потеря на валидных пикселях (`y≥0`, класс из `ev` как в `dts.data.target`):

- `T² KL` между смягчённым учителем `p^{1/T}` и `softmax(z/T)`, `T=2`;
- BCE между `s` ученика при `T=1` и `s` учителя — это та оценка, по которой ставится FAR;
- `0.25` кросс-энтропии по жёсткой метке, веса классов 1, 3, 3.

Batch-norm заморожен (режим eval, без градиента), чтобы короткий прогон не переписывал масштаб синтетики. Старт — `artifacts/stage1/unet_v810ft.pt`. AdamW, энкодер 1e-5, декодер и голова 8e-5, weight decay 1e-4, клип градиента 1, косинус к 4000 шагам. Тайл 128×256, batch 8, зеркало по x одновременно на входе, метке и мягкой цели. Два потока. Бюджет 42 минуты, чекпойнт `artifacts/ckpt/s3_distill/last.pt` не реже чем раз в 5 минут (модель, оптимизатор, scheduler, шаг, RNG, лучшая прокси-потеря). Лучшие веса — `artifacts/eval/s3_distill_unet.pt`.

Смешивания с картой ансамбля нет: сравнивается один ученик. Soup, MixStyle и RandConv не используются.

## Обучение

32 последовательности v8+v10 (30 в градиент, 2 в прокси), 3950 шагов, 2594 с, остановка по бюджету. Прокси-потеря на двух отложенных файлах: 0.475 на шаге 1, лучшая 0.191 на шаге 900 — эти веса и экспортированы. Дальше прокси болталась в 0.19–0.37, поздние шаги не взяты. Параметров 571 539, обучаемых 570 131 (BatchNorm заморожен). `real_train=0`. Сверка учителя на `seq0115`: `ok`, max `|Δs|` = 1.2e-7.

Лог: `artifacts/eval/s3_distill_train.json`. Чекпойнт: `artifacts/ckpt/s3_distill/last.pt`.

## Оценка

`scripts/s3_distill_eval.py` на весах шага 900 (`artifacts/eval/s3_distill_unet.pt`). Порог каждого метода — свой квантиль фона v8 val, дальше он заморожен. Пересчёт ансамбля совпал с публикацией (`protocol_ok`): val 0.386713 при пороге 0.860809, test 0.405276, v10 0.403898, v11 0.403900.

События val (≥30 % пикселей события): 81/151 и 0/28 слабых (≤2 °C); у ансамбля 84/151 и тоже 0/28. Test: 101/206 и 1/57 слабых против 104/206 и 1/57. Hot/cold IoU на val: 0.316 / 0.588 против 0.343 / 0.586.

До полосы «близко» (опубликованный val минус 0.015, то есть 0.3717) ученик не дошёл. Вложенный прирост k=5 отрицательный (−0.011), v10 и v11 ниже опубликованных констант примерно на 0.055. Абсолютный бар `nested_verdict` 0.3897 не пройден: худший micro ученика 0.352, у ансамбля 0.363. Решение в JSON: `beats=false`, `close=false`, `reason=val,nested,transfer,not_close`. Строка `BEATS_WINNER` не записана. В лог событий добавлено `DISTILL_REJECT` (23:06 UTC).

Сравнение — один прямой проход U-Net ширины 16, без усреднения с картой ансамбля. Сбор 45 файлов v8 val занял 128 с, весь прогон — 421 с. Реальные CSV не читались.
