# S3. Раздельные пороги по полярности

Без дообучения. Карты уже посчитанного ансамбля `ens_u2ft_tcn_lgbm`: `s` — вероятность аномалии, `h` — знак (`h > 0` нагрев, `h <= 0` охлаждение). Файлы `artifacts/pred/{v8,v10,v11}/ens_u2ft_tcn_lgbm`. Скрипт `scripts/s3_polthr.py`.

Один порог на `s` тратит весь бюджет FAR 1e-3 туда, где хвост фона выше. У этого ансамбля горячий фон занимает большую часть клеток, и опубликованный порог v8 val (0.8608) почти целиком режет горячий хвост. Холодные клетки с меньшим `s` до порога не доходят.

## Правило

Предсказание:

- нагрев, если `h > 0` и `s >= thr_hot`;
- охлаждение, если `h <= 0` и `s >= thr_cold`.

Фон — `valid & ev == 0 & nu == 0`, как в `scripts/eval_stage1.py`. Число фоновых тревог `K` то же, что у `metrics.far_threshold` при FAR 1e-3: индекс `k = ceil((1-far)*n) - 1`, `K = n - k - 1`. Доля `alpha` этого бюджета отдаётся горячей полярности, `K - round(alpha*K)` — холодной. Порог полярности — порядковая статистика её собственного фона, с тем же `+1e-12`.

Сетка `alpha` от 0 до 1 с шагом 0.025 (41 точка). Выбор — максимум пиксельного IoU на v8 val. При равном IoU ближе к FAR 1e-3, затем выше F1, затем `alpha` ближе к 0.5. Пороги заморожены для v8 test, v10 test и v11 test. Реальные CSV и карточки не читаются.

Общий порог ансамбля считается тем же проходом и сравнивается с `artifacts/eval/r7_ens_u2ft_tcn_lgbm.json` (val IoU 0.3867, test 0.4053). `BEATS_WINNER`, только если val IoU раздельных порогов выше 0.3867 хотя бы на 0.003.
