# RandConv

Дообучение U-Net случайными свёртками по Xu et al., ICLR 2021. Только синтетика v8. Реальные CSV и `real_noise_psd.npz` не читаются: в обучение не входят ни спектр фона, ни оценки φ.

## Метод

Старт — `artifacts/stage1/unet_v810ft.pt`, ширина 16. BatchNorm (статистика и affine) заморожен. Потеря задачи — `focal+tversky_ce`, AdamW 1e-4, weight decay 0, клип градиента 1.

На каждом батче три вида RandConv, как в алгоритме статьи:

- ядро k равномерно из {1, 3};
- веса Θ ~ N(0, 1/(C k²)), C = 3 входных канала;
- свёртка с дополнением, размер тайла сохраняется;
- смесь α x + (1−α) (x ∗ Θ), α ~ U(0, 1) отдельно на образец.

Потеря: задача на первом виде плюс λ = 1, KL каждого вида к среднему softmax трёх видов. На валидации и в ансамбле RandConv выключен: сеть видит чистый тайл.

Чекпойнт — максимум прокси-IoU@FAR 1e-3 на первых 8 последовательностях v8 val, чистый вход. Официальная цифра — полный v8 val.

Ансамбль с победителем фиксирован заранее: score = 0.5 * (`ens_u2ft_tcn_lgbm` + U-Net). Порог каждого кандидата — квантиль FAR 1e-3 его собственного фона v8 val. Test порог не двигает.

Вложенная проверка идёт той же процедурой, что `scripts/s3_sel2_cv.py`: `sequence_folds` по отсортированным последовательностям, k = 2 и k = 5, компактный фон до 200 000 клеток (`s3_sel_eval._indices`), порог и IoU только на holdout, micro-IoU — сумма tp/fp/fn (`s3_sel_core`). Прирост = min(k=2, k=5) смеси 0.5 минус тот же минимум у одного победителя. Принять метод, если этот прирост не меньше 0.003 и полный val смеси тоже выше победителя. Alpha по сетке 0…1 выбирается только внутри train-фолда и в отбор не входит.

Сэмплер тайлов проекта по-прежнему зеркалит ось x и умножает два канала на случайный коэффициент 0.75–1.3. Это не оценка, снятая с MGTS.

## Результаты

Чекпойнт — эпоха 3, прокси-IoU на 8 последовательностях 0.2224 (старт 0.2052), остановка по терпению за 561 с. Консистентность KL около 0.05, задача около 1.5. `real_stats_used=false`.

Полный v8, порог по фону. Пересчёт победителя совпал с публикацией: val 0.386712, test 0.405276.

| кандидат | порог | val IoU | val F1 | test IoU | test F1 |
|---|---:|---:|---:|---:|---:|
| unet_randconv | 0.914536 | 0.376813 | 0.5474 | 0.360389 | 0.5298 |
| ens_u2ft_tcn_lgbm | 0.860809 | 0.386712 | 0.5577 | 0.405276 | 0.5768 |
| ens_randconv (0.5) | 0.865690 | 0.389366 | 0.5605 | 0.388904 | 0.5600 |

Полный val смеси выше победителя на 0.00265. Test смеси ниже: 0.388904 против 0.405276. Test в выбор не входил.

Вложенная проверка, та же схема, что `s3_sel2_cv.py`. Число — micro-IoU holdout.

| | k=2 | k=5 | min |
|---|---:|---:|---:|
| победитель | 0.388116 | 0.371367 | 0.371367 |
| смесь 0.5 | 0.393863 | 0.374569 | 0.374569 |
| alpha с train-фолда | 0.392269 | 0.371281 | 0.371281 |

Прирост min у смеси 0.5 равен 0.003202. Это не меньше 0.003, и полный val тоже выше, поэтому по заданному правилу метод проходит. Запас над 0.003 — 0.0002. Абсолютная планка `s3_sel_core` (0.3897) не взята: min остаётся 0.375. Alpha, выбранная внутри фолда, прироста не даёт (−0.0001).

Числа: `artifacts/eval/s3_randconv_v8.json`, обучение `artifacts/eval/s3_randconv_train.json`.
