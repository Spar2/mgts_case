# ST2. Классификатор на эмбеддингах U-Net и EventNet

Отбор этапа 2 — macro-F1 семи классов на оракульных боксах. Опубликованная планка: сырая смесь 0.5·EventNet + 0.5·LightGBM `full`, GroupKFold по `seq_id`, **0.9545** (в сводке 0.955), `artifacts/eval/stage2_v8.json`. Этот прогон планку не перешёл. В выпуск смесь не меняется, детектор `ens_u2ft_tcn_lgbm` не переоценивался.

Числа: `artifacts/eval/s3_st2_v8.json`, перенос: `artifacts/eval/s3_st2_robust.json`. Код: `scripts/s3_st2_embed.py`. Тест: `tests/test_s3_st2.py`.

## Модель

`EmbedFusion` склеивает три ветки одной головой.

- Свёртка вырезки 32×64×3, тот же стек, что у EventNet (`w=24`), обучается с нуля внутри фолда.
- MLP по 35 скалярам: 19 чисел `SCALAR_NAMES`, 8 формы вырезки, 8 контекста соседних боксов той же записи. Контекст считается по геометрии боксов, без их меток (`dts.events`).
- Замороженные энкодеры `artifacts/stage1/unet_v810ft.pt` (ширина 16) и `unet_w24.pt`. С каждого масштаба e2/e3/e4 берутся среднее, std и разность «центр минус край» по оси x. Склейка — 1680 чисел. Это признаки сегментации фона/нагрева/охлаждения, не семиклассовая голова.

Обучение: AdamW `2e-3`, weight decay `1e-3`, сглаживание меток 0.05, веса классов с потолком 10, отражение вырезки по x в обучении и среднее двух проходов на оценке. 20 эпох, batch 128, один seed, `torch`/`OMP` = 2. Нормы скаляров и эмбеддингов считаются по обучающим строкам фолда. Test в нормы не входит.

Абляция без ветки U-Net в этот прогон не вошла: на 8 ядрах одновременно шли другие задачи, полный график 2×30 эпох не успевал к отчёту. Цифра 0.903 относится к полной склейке.

## Протокол

GroupKFold(5) по `seq_id` на `split != test` (1780 боксов, test 347). Те же группы и тот же `artifacts/stage2/dataset_v8.npz`, что у опубликованного этапа 2. Контроль протокола: rules на dev **0.3280** (опубликовано 0.328), LightGBM `full` заново **0.9473** (опубликовано 0.9473).

Энкодеры U-Net учились сегментации на train v8 (v810ft ещё и на train v10) с ранней остановкой по val v8. Семиклассовая голова фолда группы своего val не видит. Test, v11 и v12 в голову не входят. OOF по строкам train-сплита 0.902, по строкам val-сплита 0.900: ранний просмотр val энкодером макро-F1 не раздул.

Реальные `MGTS_data/1-6.csv` в обучении, в нормах и в оценке macro-F1 не используются. У них нет меток семи классов. Карточки оператора описывают наличие события, из них класс таксономии не выводится.

## Решение

EmbedFusion остаётся измеренным вариантом и в `models_release` / `artifacts/stage2` не записывается. Планка 0.955 держится опубликованной смесью EventNet и LightGBM. Замороженные эмбеддинги сегментации на этих боксах повторяют уровень EventNet (0.903 против 0.904) и не добавляют того, что уже даёт LightGBM по форме и контексту.

Детекторный val IoU@FAR 1e-3 не считался: задача этапа 2 — класс бокса, не карта этапа 1. Строка `BEATS_WINNER` не пишется.

## Воспроизведение

```bash
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
  /workspace/repo/run/.venv/bin/python scripts/s3_st2_embed.py \
  --threads 2 --epochs 20 --seeds 1 --skip-nounet --batch 128
/workspace/repo/run/.venv/bin/python -m pytest tests/test_s3_st2.py -q
```

v12 читается из `/workspace/synth_v12/d` по одной записи, полный кэш полей не пишется.
