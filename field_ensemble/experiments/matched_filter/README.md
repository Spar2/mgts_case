# matched_filter

Согласованный фильтр без обучения. Гауссово сглаживание двух нормированных каналов ядром (2, 6), скор — максимум модулей, горячность — сумма. Функция `matched_filter` в `dts/classic.py`. Вызов только из `scripts/predict.py --method matched_filter`. Рядом в том же файле живёт `pixel_features`: его использует член победителя `pixel_lgbm` (`dts/infer.py`, `dts/domain.py`). Функция не вырезалась и остаётся в `dts/classic.py`. `scripts/predict.py` вызывает `classic.matched_filter` внутри ветки `--method matched_filter`. `pixel_features` там же, верхний `from dts import classic` в `predict.py` остаётся.

`tests/test_stage2.py` проверяет разбор порога по строке `"matched_filter"` и функцию не вызывает. Этот тест не переносится.

## Цифры

Пиксельный протокол, `artifacts/eval/stage1_v8_early.json` и тот же блок в `stage1_v8_round1.json`. Квантиль far \(10^{-3}\) на этой шкале не достигается: фактический FAR остаётся выше цели.

| точка | val IoU | val FAR | test IoU | test FAR |
| --- | ---: | ---: | ---: | ---: |
| far_1e-3 | 0.064902 | 0.006155 | 0.060379 | 0.012884 |
| far_ref | 0.085160 | 0.058082 | 0.062436 | 0.130429 |

Порог far_ref: 9.5795 при целевой доле фона 0.058082 (`artifacts/stage2_scratch/matched_filter_far_ref.json`, 45 последовательностей val, 65.1 млн фоновых клеток).

Сквозная типизация test, тот же порог, `artifacts/stage2_scratch/e2e_matched_filter_test.json`: macro-F1 0.0593, ДИ [0.0396, 0.0841], зон 2963, из них ложных 2855 (доля 0.964), совпало с эталонными рамками 108 из 345, класс верный в 65 из 108 (точность класса на совпавших 0.602). Legacy-голова (`e2e_matched_filter_test_legacy.json`): macro-F1 0.0560 при тех же 2963 зонах. Смена классификатора этапа 2 карту не спасает.

`PROGRESS_LOG.md`: matched filter test IoU 0.06 при U-Net 0.363 и эталоне median 0.013.

## Почему отклонён

Даже лучшая пиксельная точка (val IoU 0.085 на far_ref, 0.065 на попытке far \(10^{-3}\)) далеко ниже U-Net и ниже победителя 0.387 / 0.405. На test при пороге с val фактический FAR 0.013, а не \(10^{-3}\): шкала скора не отделяет хвост фона. Сквозной macro-F1 0.059 при 2855 ложных зонах. Фильтр остаётся воспроизводимым сравнением, не детектором по умолчанию.
