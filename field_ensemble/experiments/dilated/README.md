# dilated

Полносвёрточная сеть с дилатациями 1, 2, 4, 8, 16, 1, ядро 3×3, без пулинга (`DilatedFCN` в `dts/models.py`). Ширина по умолчанию 32. Обучение: `scripts/train_stage1.py --arch dilated`, вес `artifacts/stage1/dilated.pt`. Отдельного скрипта нет. Класс не вырезался: `DilatedFCN` остаётся в `dts/models.py`, `build("dilated")` берёт его оттуда. `build("unet")` и `build("tcn")` пакет `experiments` не загружают.

В членах релиза `ens_u2ft_tcn_lgbm` архитектуры `dilated` нет. TCN в победителе — другая сеть: дилатации только по времени плюс ядро 3 по кабелю. Её не вырезать.

На точке far_ref dilated ещё слабее: val IoU 0.0988, test 0.0895. `PROGRESS_LOG.md` по раннему сравнению этапа 1 пишет test IoU dilated FCN 0.326 при U-Net 0.363.

## Почему отклонён

Val IoU 0.298 ниже U-Net (0.368) и ниже порога отбора 0.387. Большое поле зрения без пулинга не компенсировало отсутствие многомасштабного энкодера на мелких очагах. Класс остаётся вызываемым для старых карт `artifacts/pred/*/dilated/`, в дефолтный анализатор не входит.
