# S3 Flow

Одношаговый rectified flow фона (REFLECT: один эйлеров шаг, без VAE и без 1000 шагов DDPM).
Учится только на тайлах синтетики v8 и v10 train, где нет события и nuisance.
Инференс при t=0.5: поле скорости переводит зашумлённый dT к норме.
Скор — CDF модуля остатка (узлы с holdout-фона train). Знак нагрев/охлаждение — знак остатка dT.
Ансамбль фиксирован до val: (4 × ens_u2ft_tcn_lgbm + s_flow) / 5.
Порог FAR 1e-3 — квантиль фона всего v8 val. v10 и v11 этот порог не двигают.
Реальные CSV в обучение и в выбор порога не входят.

Решение: **отклонён**.

Отклонено. Val ансамбля 0.3820 против победителя 0.3867. Вложенный прирост -0.0113 (нужно ≥ 0.003). v10 ансамбль 0.4076 / победитель 0.4039, v11 0.4075 / 0.4039. Победитель не заменяется.

## Обучение

Лучшая эпоха 15, прокси -0.27136479126985785, остановка patience, 892.1 с.
Проба копирования: restore 0.3367026616377044, denoise 0.1585098106618555, фон |остаток| 0.6080674529075623.
restore около 0 и denoise около 0 — сеть копирует вход. Оба около 1 — всплеск и шум снимаются.
