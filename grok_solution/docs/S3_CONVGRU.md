# S3. ConvGRU в бутылочном слое U-Net

Нейросетевой детектор. Порог — квантиль фона synth v8 val при FAR 1e-3, не z-статистика. Реальные CSV и спектр шума МГТС в обучение и в порог не входят. Карточки оператора модель не выбирают.

## Архитектура

`dts/convgru.py`. Костяк — `DTSUNet` ширины 16: те же `e1`…`head` и TimeGate, поэтому `artifacts/stage1/unet_v810ft.pt` садится на веса (571 539 параметров костяка). После TimeGate стоит ConvGRU (Ballas, Yao, Pal, Courville, 2016, «Delving Deeper into Convolutional Networks for Learning Video Representations»): на каждом шаге времени три свёртки ядром 1×3 по кабелю дают вентиль обновления, вентиль сброса и кандидата.

Состояние

`h_t = (1 − z_t) ⊙ h_{t−1} + z_t ⊙ tanh(W_n ∗ x_t + U_n ∗ (r_t ⊙ h_{t−1}))`.

ConvLSTM (Shi et al., 2015) здесь не стоит: отдельная ячейка памяти удвоила бы рекуррентные свёртки на CPU. Длинный контекст делается переносом `h` между тайлами инференса. Сетка тайлов та же, что у `models.predict_full` (256×512, перекрытие 32). Внутри одной колонки кабеля следующий тайл получает состояние последней строки бутылочного слоя, которая ещё не входит в новый тайл (шаг в пикселях, делённый на 8). Последний неровный тайл кадра берёт целую часть этого шага.

Выходная свёртка 1×1 инициализирована нулём. До обучения остаток равен нулю, и сеть совпадает с U-Net на тех же весах. Невалидная клетка 8×8 состояние не обновляет. Всего 883 603 параметра, из них ConvGRU 312 064.

## Обучение

`scripts/s3_convgru_train.py`. Только `artifacts/cache/v8/train` (mmap уже есть) и `artifacts/cache/v10/train` (npz, новый mmap не пишется). Потеря `focal+tversky_ce` плюс 0.05 · средний квадрат оценки аномалии на пикселях фона и L2 выходной проекции с весом 20. Остов и BatchNorm заморожены: шаг по всему U-Net ронял порог прокси. Учится только ConvGRU, шаг 1e-5. На паре тайлов потеря усредняется. Тайл 128×256, batch 4. С вероятностью, когда длина кадра позволяет, второй тайл сдвинут на 96 отсчётов времени и читает состояние первого: так градиент видит стык тайлов. Зеркало только по кабелю, множитель шума 0.75–1.3 — синтетический, не спектр МГТС. Шаги по очереди v8 и v10. Потолок 45 минут, 2 потока.

Чекпойнт — максимум прокси IoU@FAR 1e-3 на четырёх последовательностях v8 val (индексы 0, 11, 22, 33). Это не официальная цифра. Старт тоже участвует в сравнении.

## Отбор

`scripts/s3_convgru_eval.py`. Кандидаты до просмотра test:

| имя | состав |
| --- | --- |
| convgru | дообученная сеть |
| ens_blend | среднее `ens_u2ft_tcn_lgbm` и convgru |
| ens_replace | среднее `unet_w24`, convgru, tcn, `pixel_lgbm` |

Выбор — максимум пиксельного IoU на всех 45 последовательностях v8 val. Test тем же порогом.

Вложенная проверка идёт через `scripts/s3_sel2_cv.py`: `sequence_folds`, `eval_one`, `pack_metrics`, сетка `ALPHAS`, а планка — `s3_sel_core.nested_verdict` (строго выше 0.3867 + 0.003). Пять фолдов по порядку имён, `i % 5`. Компактный фон — до 200 000 клеток на файл, как в SEL2. Порог FAR и IoU считаются на holdout. Три заранее заданных прохода: замороженный рецепт, выбранный по полному val; выбор кандидата заново на train-фолде; доля карты победителя `alpha` на train-фолде. Приёмка и `BEATS_WINNER` — только если протокол пересчёта победителя сошёлся, вложенный 5-fold замороженного рецепта строго выше 0.3897 и полный val тоже выше 0.3867 хотя бы на 0.003.

## Результаты

Дообучение `scripts/s3_convgru_train.py` шло 1129 с и остановилось по терпению после эпохи 8. Прокси IoU@FAR 1e-3 на `seq0006`, `seq0112`, `seq0157`, `seq0207` стартовал с 0.203625 (порог 0.758882) и на эпохах 0–8 оставался ниже: 0.203266–0.203568, порог 0.756–0.759, L1 проекции не выше 0.330. Чекпойнт — эпоха −1, `artifacts/eval/s3_convgru_unet.pt`: выходная проекция нулевая, сеть совпадает с `unet_v810ft`. Реальные CSV, карточки оператора и спектр шума МГТС в обучение и в порог не входили.

Официальные цифры — `artifacts/eval/s3_convgru_v8.json` (546 с). Пересчёт `ens_u2ft_tcn_lgbm` сошёлся с публикацией без остатка: val 0.38671235821914546, test 0.4052762065230473, порог 0.8608087301264272. Фон val: 65 095 696 клеток, FAR val 0.001000.
