# S3 MAE

Маскированный реконструктор фона. Это не rectified flow и не поле скорости.
Учится на синтетике v8 и v10 train, преимущественно на тайлах без события.
Маска — полосы по расстоянию. Цель — восстановить dT_space и dT_time в скрытых клетках.
Скор — CDF |остаток dT_space|. Знак нагрев/холод — знак остатка dT_time.
Смеси с ens_u2ft_tcn_lgbm фиксированы до val: mean, max и (4×победитель + mae)/5.
Победитель смеси выбран по val IoU. Вложенная проверка этот выбор не переигрывает.
Порог FAR 1e-3 — квантиль фона всего v8 val. v10 и v11 этот порог не двигают.

Принять только если val IoU > 0.38671235821914546, вложенный прирост k=5 не меньше 0.003, min(k=2, k=5) > 0.3897, и v10/v11 test не хуже победителя. Порог FAR 1e-3 считается по фону v8 val. Реальные трассы не участвуют в обучении и пороге. Обучение — синтетика v8+v10, преимущественно фон.

## Почему test > val

Кандидат ens_mean4 остаётся опцией `mae=on`. По умолчанию `mae=off`. Числа ниже — разложение уже посчитанного прироста, порог не перевыбирался. Полные кривые: `artifacts/eval/s3_mae_why.json`.

Выпущенный реконструктор — init, `best_epoch=-1`. Голова нулевая, `hat=0` на любом входе, max |веса головы| = 0. Свёртки init (max |ядро| 0.129) на скор не влияют: ответ члена — CDF(|dT_space|). Канал dT_space и так фиксированный пространственный фильтр: температура минус скользящая медиана по x (окно 40 м) и минус синфазная, в единицах σ, клип ±12. Это не отдельный высокочастотный фильтр случайной сети.

Смесь (4×победитель + CDF(|dT_space|))/5 сравнивалась с ens_mean4 попиксельно на всех файлах v8 val, v8 test, v10 test и v11 test. max |Δ скора| = 0, расхождений порога 0. Прирост IoU один и тот же. Это пост-фильтр контраста, сеть эпох не добавляет. На одном тайле 128×256 даже kaiming-голова (bias 0) даёт |hat| среднее 0.0025 и corr(остаток, dT_space) = 1.000; это не метрика сплита.

MAE один не детектор. У CDF 122 плато из 256 шагов, квантиль FAR 1e-3 попадает в атом 0.53125. На v8 val эмпирический FAR 0.08835, precision 0.0531, recall 0.3730, IoU 0.0488 (fp фона 5.75e6 из 6.60e6). Вес 1/5 только двигает хвост победителя. Средние по фону этого не показывают: P(MAE < победитель) на чистом фоне val всего 0.045, на событии 0.71.

Порог 0.763 против 0.861 — квантиль своей шкалы на одном и том же чистом фоне v8 val (оба FAR 0.001000, fp фона оба 65096). Бюджет ложных по чистому фону не ослаблен.
