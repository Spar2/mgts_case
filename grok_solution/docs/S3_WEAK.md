# S3 WEAK — recall событий ≤ 2 °C

Дообучение U-Net на слабые события. Правило выбора то же, что у этапа 1: val IoU при FAR 1e-3 на synth v8, порог — квантиль фона v8 val. Победитель `ens_u2ft_tcn_lgbm`: val IoU 0.387, test IoU 0.405. Его эта строка не бьёт.

## Данные

Обучение — только synth **v10 train** (210 последовательностей, 60 с событием ≤ 2 °C). Старт — `artifacts/stage1/unet_v810ft.pt`, ширина 16.

Кэша `artifacts/cache/v11/train` нет (в labels train есть, на диске только val и test). Кэша `artifacts/cache/v12` нет. Оба в градиент не входили.

Порог и ранний отбор — фон **v8 val**. Test в выбор не входит. Реальные MGTS не читались: ни обучение, ни порог, ни калибровка. Меток амплитуды на них нет, `by_amp` по ним не считается, карточки не использовались.

## Метод

Потеря — focal (γ = 2) + Tversky (α = 0.7 на FN, β = 0.3). Вес пикселя `(2 / amp)^γ` при амплитуде ниже 2 °C и потолке 4; при амплитуде ≥ 2 °C вес остаётся 1, сильные события не занижаются.

Отдельный хинж тянет верхние 30 % пикселей слабого события к вероятности 0.96. Ранжирование против локального хвоста фона убрано: оно поднимало глобальный порог FAR вместе с пиками. Фон якорится к замороженной копии стартового U-Net: штраф, если ученик на фоне увереннее учителя.

Curriculum, 6 эпох: потолок выборки 8 → 2 °C, доля тайлов на малых событиях 0.20 → 0.80, γ веса 0.40 → 1.60. Batch-norm заморожен. LR декодера 8e-5, энкодера 1e-5, 2 потока, 50 шагов, batch 6, тайл 128×256. Обучение 730 с.

Чекпойнт — эпоха 2 (`artifacts/s3_weak/unet_s3_weak.pt`). На прокси из шести файлов v8 val (слабые `seq0242`, `seq0111`, `seq0177` и тяжёлый хвост `seq0086`, `seq0115`, `seq0224`) IoU 0.289 против 0.282 у старта, recall ≤ 2 °C остался 0/18. Эпохи 3–5 отброшены: при замороженном пороге старта FAR вырос с 0.001 до 0.0036–0.0039, попаданий ≤ 2 °C по-прежнему не было.

## Оценка

Порог — то же правило, что `dts.metrics.far_threshold`. Для ансамбля он совпал с опубликованным **0.86080873**, val IoU **0.3867** и test IoU **0.4053** совпали с `artifacts/eval/r7_ens_u2ft_tcn_lgbm.json`. Событие засчитано, если закрыто ≥ 30 % его пикселей (`by_amp` в `scripts/eval_stage1.py`). На val в знаменателе 28 событий ≤ 2 °C: один бокс из labels не имеет пикселей на сетке. На test их 57.

`s3_weak` — дообученный U-Net. `s3_weak_max` и `s3_weak_or` — max и noisy-or его карты с замороженным ансамблем; порог каждой карты считается заново по фону v8 val. В выбор по val IoU среди новых карт входит `s3_weak_or`.

FAR на test при пороге с val: U-Net 0.00204, ансамбль 0.00232. Hot / cold IoU на test: U-Net 0.364 / 0.396, ансамбль 0.406 / 0.398.

## Что не принято

Recall ≤ 2 °C при FAR 1e-3 не вырос. Val IoU лучшей новой карты 0.383 ниже 0.387. Победитель не сменяется, строки `BEATS_WINNER` нет.

На test 35 из 57 событий ≤ 2 °C — это `tracing`: медиана около 3 минут и 0.4 м, одна-две клетки при амплитуде около 1 °C. Порог 99.9 % фона сидит на 0.86–0.93. Эпохи, которые сильнее давили на малую амплитуду, поднимали хвост фона быстрее пиков этих клеток: порог прокси уехал с 0.984 к 0.997, recall ≤ 2 °C остался нулём. Мягкая эпоха 2 хвост удерживает и IoU на прокси чуть растит, но до порога FAR 1e-3 слабые события не доходят.

Полный отчёт: `artifacts/eval/s3_weak_v8.json`. Лог эпох: `artifacts/s3_weak/train_log.json`.

## Кривая FAR для событий ≤ 2 °C

Нового обучения нет. Пороги — квантиль фона v8 val (65 095 696 клеток), то же правило, что `dts.metrics.far_threshold`, затем заморожены и применены к test v8, v10 и v11. Сетка FAR — от 1e-4 до 3e-2. Победитель — `ens_u2ft_tcn_lgbm`, счёт `s`. Эталон — `base_median_x3_spatial_z`, счёт `|base_z|`. Событие засчитано, если порог закрывает ≥ 30 % его пикселей. SNR события — `amp_obs_C / медиана σ(x)` по его столбцам дистанции. Уровень 50 % — логарифмическая интерполяция event recall по трём бинам амплитуды, упорядоченным по медиане этого SNR.

Контроль: порог ансамбля при FAR 1e-3 равен **0.86080873** и совпадает с опубликованным. Порог `|Z|` на той же точке 10.586 (на 1e-4 / 1e-2 / 3e-2: 12.82 / 5.43 / 4.19). У ансамбля те же точки дают 0.980 / 0.395 / 0.211. На test v8 при FAR 1e-3 ансамбль снова даёт 1/57 и пиксельный recall 0.013 — те же числа, что в оценке выше. Ось рисунка — номинальный FAR, по которому резали фон v8 val. Фактический FAR на test выше у ансамбля: при номинале 1e-3 это 0.00232 / 0.00182 / 0.00182 на v8 / v10 / v11, при номинале 3e-2 — 0.058 / 0.056 / 0.056. У `|Z|` фактический FAR чуть ниже номинала (0.00086 / 0.00062 / 0.00062 и 0.026 / 0.027 / 0.027).

Интерполяция по трём бинам грубая: у ансамбля 50 % лежит между бином 2–5 °C (recall 0.34–0.45) и бином >5 °C (recall 0.81–0.82). Мелкая сетка SNR по всем событиям, бины с n ≥ 5, даёт ту же границу чуть ниже: 14.0 / 12.2 / 12.4. На ней recall ансамбля при FAR 1e-3 равен нулю для amp/σ < 6, около 0.08 в бине 6–8 и 0.56–0.61 в бине 12–20.

У `|Z|` при FAR 1e-3 половина не набирается и в бине >5 °C (recall 0.21–0.23, пиксельный около 0.019). На мелкой сетке лучший заполненный бин 20–40 даёт 0.30–0.36, бин 40–80 имеет n = 6 и recall 0.17, восходящего пересечения 0.5 нет. Половина появляется у `|Z|` только к FAR 1e-2: amp/σ 20.8 / 18.8 / 18.8, амплитуда 5.8 / 5.4 / 5.4 °C.

Как уровень 50 % у ансамбля едет вместе с бюджетом FAR: при 1e-4 это amp/σ 24.8 / 29.2 / 29.1, при 1e-2 — 7.9 / 7.7 / 7.7, при 3e-2 — 4.5 / 5.0 / 5.2. Даже на правом краю сетки медиана слабых событий (3.4–3.5) остаётся ниже этой границы, и их event recall не доходит до половины: 22/57, 19/60, 18/60.

## Физический предел

Слабое событие на этих тестах — амплитуда около 1 °C при шуме столбца около 0.3 °C, amp/σ около 3.5. Рабочий порог FAR 1e-3 у ансамбля сидит на счёте 0.86, у пространственной z-статистики — на 10.6. При таком пороге ансамбль набирает половину событий только с amp/σ 14–17 (амплитуда 4.1–4.9 °C). Слабый бин в 4–5 раз ниже и даёт 1/57 на v8 и 0/60 на v10 и v11. Эталон `|Z|` на этой точке не набирает половину даже у событий >5 °C.

Ослабление порога до номинального FAR 3e-2 (на test у ансамбля это уже около 0.056) поднимает слабый event recall до 0.30–0.39 и пиксельный до 0.16–0.23. У `|Z|` на том же краю остаётся 1–2 события из 57–60. Дообучение U-Net на малую амплитуду этот пол не сдвинуло: при FAR 1e-3 recall ≤ 2 °C остался 1/57. Предел задаёт контраст события к шуму при бюджете ложных тревог, а не выбор головы.
