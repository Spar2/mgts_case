# multiscale

Слияние карты победителя с той же картой, пересчитанной на прореженной сетке. Блоки `t2`, `t4`, `x2`, `x4`. Смеси: `native` (исходный масштаб как есть), `max`, `mean`, `noise` (вес блока = число усреднённых отсчётов). Код: `experiments/multiscale/multiscale.py`, `experiments/multiscale/run_multiscale.py`. Обучения нет. Порог каждой смеси снят с v8 val при FAR \(10^{-3}\).

Это не архитектура `unet_ms`. Интегрирующий вход U-Net описан в `experiments/unet_ms/README.md`.

## Цифры

`artifacts/eval/s2_ms_v8.json`, выбор по v8 val IoU. Победитель внутри файла — строка `native` (та же карта `ens_u2ft_tcn_lgbm`).

`artifacts/eval/s2_ms_real.json`: выбрана смесь `native`, порог 0.8608, карточки 8/15 и 0/5, зоны 138. Это повтор победителя, не новый детектор. Заметка файла: box15 не применяется.

## Почему отклонён

Селектор оставил `native`. Ни одна смесь не подняла v8 val IoU выше 0.3867. Ближайшая, `max_t2`, даёт 0.3678 на val. Модуль не меняет выпущенную карту, поэтому в дефолтный инференс его не включают. Скрипт читает уже посчитанные карты ансамбля и сам ходит в `dts.models` / `dts.classic.pixel_features`; после переноса эта зависимость от ядра сохраняется, обратной нет.
