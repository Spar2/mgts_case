# unsup

Leave-one-file-out слепой прогнозист на шести CSV МГТС. Широкая дырка: 41 точка по кабелю (около 10 м) не читается ни в одном кадре, будущее не читается, прошлое соседей берётся с лагом 15 строк. Бутылочное горло 4 канала, ширина 8. Остаток — канал 0 `make_channels` минус прогноз, скор \(|r|/(1{,}4826\cdot\mathrm{MAD})\). Порог — квантиль своего файла, доля \(10^{-3}\), без карточек. Код: `experiments/unsup/unsup.py`, `experiments/unsup/run_unsup.py`, описание `experiments/unsup/UNSUP.md`. Модель на файл не дольше 8 минут, 2 потока.

Протокол сам учится на реальных файлах без меток. Для нового дефолтного контура это закрыто: CSV только оценка. Чистка увозит код в `experiments/unsup/`, JSON и CSV в `artifacts/unsup/` не трогает. `scripts/real_gap.py` читает эти CSV и модуль не импортирует, его не переносить.

## Цифры

`artifacts/eval/unsup_real.json`.

Синтетика v8, порог с val-фона (7.983), test IoU 0.2121, F1 0.3500, FAR 0.00307, ДИ IoU [0.118, 0.324]. Квантиль порога по каждому файлу отдельно роняет test IoU до 0.0329. Обучение на 16 файлах, 480 с. Зонд в конце: фон 0.735, горб события 8.068 (горб внутри дырки не восстановился, это проверка слепоты, не метрика детекции).

Опубликованные соседи в том же JSON, test v8: U-Net IoU 0.3625, `ens_unet_tcn_lgbm` 0.4025, эталон 0.0125, ssl-AE 0.0023.

Карточки: yes 3/15, no 0/5 (`presence`). Реплей выпущенного детектора в том же файле: yes 8/15, no 0/5, порог 0.8438.

## Почему отклонён

На синтетике IoU 0.212 ниже U-Net (0.363) и ниже победителя (val 0.387 / test 0.405). На карточках 3/15 против 8/15 у релиза, при тех же 0/5 на пустых рамках. Слепая дырка лечит провал автоэнкодера (0.002), но не доходит до сегментации, обученной на метках синтетики. В дефолтный `Analyzer` модуль не входит, и новый прогон не должен снова учиться на `1–6.csv`.
