# stack/archive — архив стендовых скриптов

Что здесь: `chaos.sh` (хаос-тесты стенда) и `backup.sh` (restore-point бэкап).
Статус: АРХИВ. НЕ ЗАПУСКАТЬ. Файлы сохранены только для истории.
Почему: стендовые сценарии выведены из активного использования (вариант В1).
Старые пути `stack/chaos.sh` и `stack/backup.sh` — заглушки с `exit 3`.
Симлинки не используются: заглушки — обычные файлы, архив — обычные файлы.
Дата архивации: 2026-10-13.
Подробности сценариев — внутри самих файлов, запускать их нельзя.
