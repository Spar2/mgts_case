# Архитектура и запуск

Снимок ветки `ml` репозитория `werd0y45/haklolarp`, коммит `71fc4eb` (16 октября 2026). В `main` этот снимок не вливался. Архив — исходный код пайплайна и моделей для письма в Центр карьеры. Сырых CSV и большинства обученных весов в git нет, поэтому их в архиве тоже нет.

Публичное имя продукта: «Единая аналитическая платформа сенсорных данных». Данные — температура вдоль оптического волокна в помещении, шесть файлов `1.csv`–`6.csv`. Значение `−300` — пропуск измерения, не температура.

## Что делает рабочий контур

Рабочая обработка на ветке `ml` не заменена нейросетью.

1. CSV читается в поле «время × метры» и маску пропусков.
2. Канал очистки — скользящая медиана по длине `median_x3`.
3. Кандидат зоны ставит пространственный Z-score с ореолом `spatial_z_halo`.
4. Форма зоны подписывается отдельно. Это гипотеза по форме пятна, не подтверждённое событие и не причина.

Нейросети, сканеры кропа и логистические модели на контексте — исследовательский зоопарк. Они сравнивались со свидетелями и рабочий статус не сменили. Цифры в `docs/SCORECARD.md` относятся к своим протоколам, это не оценка жюри и не доля найденных аварий.

## Где лежат папки

| Папка | Что это |
| --- | --- |
| `fiber/` | Пайплайн: чтение, очистка, аномалии, классы формы, API. Сборка шагов — `fiber/pipeline.py`. |
| `fiber/models/` | Код архитектур: 1D CNN Noise2Self, 2D U-Net, conv-AE, классификатор кропа, остаточная CNN, граф колонок, трансформер. |
| `fiber/denoise/`, `fiber/anomaly/`, `fiber/classify/` | Реализации шагов. |
| `scripts/` | Команды, которыми этот пайплайн гоняют. |
| `tests/` | Проверки без CSV и без GPU. |
| `ml_common/` | Общие схемы, протокол и CLI соседнего слоя. |
| `models/weights/` | Куда обучение кладёт `*.pt`, `*.onnx`, `*.pkl`. В git только `README.md`: каталог в `.gitignore`. |
| `research/ml-test-review/weights/` | Шесть маленьких CNN-весов, которые в git есть. Исследовательские, тревогу не ставят. |
| `research/real-data-v2/real_masked_ridge.json` | Веса ridge только на реальных измерениях. Тоже не рабочий детектор. |
| `solutions/larpathon/` | Отдельный прототип ансамбля на неразмеченных профилях. Код, тесты и `weights/synth_patch_net.pt`. Большие картинки отчётов в этот архив не входили. Метки вроде нагрева и охлаждения там — правила формы при отсутствии разметки. |
| `docs/` | Постановка, решения и таблицы скоров. Команды дня — `docs/PIPELINE.md`. |
| `pyproject.toml` | Зависимости пакета `haklolarp-ml`. |
| `compose.ml.yaml` | Контейнер API ветки `ml`, если нужен Docker, а не локальный Python. |

Веб-интерфейс в этот архив не входил. Он живёт в ветке `web`, каталог `apps/web`.

## Что нужно на машине

- Python 3.11 или новее. На машине с RTX 4080 SUPER стоит 3.13 и CUDA torch. Для тестов и шагов без обучения видеокарта не нужна.
- Шесть CSV рядом с репозиторием, в каталоге `MGTS_data` (или другой путь в аргументе `--raw-root`). В архиве и в git этих файлов нет.
- Команды ниже запускать из корня распакованного архива.

Установка:

```powershell
python -m pip install -e ".[dev]"
```

Обучение и применение сетей:

```powershell
python -m pip install -e ".[train]"
```

## Как прогнать рабочий контур

```powershell
python scripts/transform_csv.py --raw-root MGTS_data --out-root artifacts/records
python scripts/denoise_records.py
python scripts/detect_anomalies.py
python scripts/plot_anomaly.py
python scripts/classify_zones.py
```

После первого шага на каждый файл появляются `raw_c.npy`, `valid.npy`, `x_m.npy`, `time_s.npy`, `meta.json`. Индекс шести записей — `artifacts/records/index.json`. Каталог `artifacts/` создаётся прогоном и в git не хранится.

Один файл и два метода очистки:

```powershell
python scripts/denoise_records.py --only 5 --methods median_x3 wavelet_x
```

Проверка кода без данных и без GPU:

```powershell
python -m pytest tests -q
```

Локальный API обработки:

```powershell
python -m uvicorn fiber.api:app --host 127.0.0.1 --port 8082
```

Проверяются `GET /health`, `GET /methods`, `POST /denoise/profile`.

## Как обучить модели

Веса пишутся в `models/weights/` на машине с CUDA. В этом архиве их нет, пока команды ниже не выполнены локально.

```powershell
python scripts/train_conv_ae.py --device cuda
python scripts/train_conv1d_n2self.py --device cuda --epochs 8
python scripts/train_unet2d_denoise.py --device cuda --epochs 6 --crops 4000
python scripts/train_patch_classifier.py --device cuda --epochs 16
```

Применить уже лежащий файл весов 1D-сети к записи 5:

```powershell
python -c "from pathlib import Path; from fiber.io import Record; from fiber.denoise import apply_method; r=Record.load(Path('artifacts/records/5')); d=apply_method('conv1d_n2self', r.raw_c, r.valid, weights=Path('models/weights/conv1d_n2self.pt')); print(d.shape)"
```

Остальные команды обучения и правило, какая модель вообще допускается к скану сырых файлов, записаны в `docs/PIPELINE.md` и `models/weights/README.md`. Коротко: скан сырой трассы запускается только если отчёт выбора назвал именно эту модель. На измеренных прогонах рабочий статус так и остался у `spatial_z_halo`.

Прототип `solutions/larpathon` ставится отдельно:

```powershell
python -m pip install -r solutions/larpathon/requirements.txt
python -m pytest solutions/larpathon/tests -q
python solutions/larpathon/main.py --help
```

## Технологии

Python, NumPy, SciPy, pandas, PyWavelets, Matplotlib, FastAPI и Uvicorn. Обучение: PyTorch и, отдельно, LightGBM. Контейнер API описан в `compose.ml.yaml`. Хранилище стенда (ClickHouse, Redis, Postgres) к этому архиву не относится и для письма с кодом пайплайна не требуется.

## Чего в архиве нет

- Файлов `1.csv`–`6.csv` и каталога `artifacts/`.
- Обученных весов из `models/weights/`, кроме README. Их производит локальное обучение.
- Картинок и zip-отчётов из `solutions/larpathon/reports/`.
- Веток `web` и `main`, секретов, Ansible и боевого стенда.
