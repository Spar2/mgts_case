# Продолжение актуального веб-интерфейса

**UI ЗАМОРОЖЕН по прямому поручению пользователя 15 октября 2026.**
Сначала прочитать `../../docs/web/UI-FREEZE.md`. Без явного разрешения на
конкретную правку неприкосновенны весь лендинг, все разделы, их состав/порядок,
тексты, общий дизайн, меню, маршруты, стартовые страницы, переключения, фокус,
прокрутка и правила загрузки/сохранения данных. Общая задача по улучшению или
ML-интеграции не разрешает менять UI. Исправлять конкретный явно порученный
баг можно только в его границах; не расширять его до редизайна.

Проверить эталон: `python ../../scripts/check-web-ui-freeze.py`.
Не обновлять manifest, не ослаблять проверки и не удалять эти правила без
пользовательского разрешения. Для новой модели: готовый промпт
`../../docs/web/GROK-WEB-GUARDRAILS.md`.

1. Работать одним агентом; сохранить изменения других участников.
2. Источник текущего UI — код выбранной версии в `apps/web/src`. Правила: `design/README.md`, `docs/web/STYLE-AND-IDENTITY.md`, `docs/web/design-system/ui-contract.json`.
3. Не читать/редактировать `design/archive/` и не брать оттуда шаблоны для обычной веб-задачи. Нужен прямой запрос пользователя именно на архив.
4. Синхронизированный актуальный Pen и каноническая свежая PNG-галерея не подтверждены. Не подставлять старые файлы вместо них.
5. Сохранять Carbon, IBM Plex, обе темы White/Gray 100 и общие токены поверхностей и действующие контракты/маски/source SHA/run ID. Не менять авторизацию ради дизайна.
6. Проверять изменённый экран и состояния в правильной сборке, отдельно от build. Исторический screenshot не подтверждает новую версию.
7. Не выполнять push/merge/deployment без соответствующего поручения; текущие инструкции пользователя имеют приоритет.
